## Network > Network ACL > 릴리스 노트 { #network-network-acl-release-notes }

<a id="may-28-2024"></a>
### 2024. 05. 28. { #may-28-2024 }

<a id="may-28-2024-added-features"></a>
#### 신규 기능 추가

* 한국(판교) 리전에 Network ACL 기능이 추가되었습니다.
* Network ACL이 CloudTrail에 연동되었습니다.

<a id="august-29-2023"></a>
### 2023. 08. 29. { #august-29-2023 }

<a id="august-29-2023-added-features"></a>
#### 신규 기능 추가

* 한국(평촌) Public API가 출시되었습니다. [Network ACL API 가이드](https://docs.nhncloud.com/ko/Network/Network%20ACL/ko/public-api/)를 참고하세요.

<a id="august-25-2020"></a>
### 2020. 08. 25. { #august-25-2020 }

<a id="august-25-2020-added-features"></a>
#### 신규 기능 추가

* [한국(평촌) 리전] Network ACL 기능이 추가되었습니다. ACL 기능을 이용해 프로토콜, IP, 포트별로 접근을 제어할 수 있습니다.
