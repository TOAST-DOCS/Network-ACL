## Network > Network ACL > Release Notes

#### Added Features

* Released the Public API for the Korea (Pyeongchon) Region. See the [Network ACL API Guide](https://docs.nhncloud.com/en/Network/Network%20ACL/en/public-api/).

#### Added Features
